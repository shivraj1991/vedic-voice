# data — content sources and pipeline

- `sources.yaml` — every text, audio, model and tool source with its license.
- `src/vv_content/analysis.py` — deterministic word split + morphology
  **candidates** for advisor review (Vidyut lexicon/segmenter, or a corpus
  pada-pāṭha). It proposes and never decides: drafts are `verified: false`.
- `shlokas/*.yaml` — the initial seed (generated by `vv_content.seed_build`, all
  `verified: false`). After seeding, the DB is the source of truth.
- `spike/` — Milestone 0b: data fetch, DCS evaluation, draft generation
  (results in [`spike/RESULTS.md`](spike/RESULTS.md)).

```
uv sync
uv run pytest && uv run ruff check . && uv run ruff format --check .
uv run python -m spike.fetch          # Vidyut data + GRETIL texts → vendor/ (gitignored)
uv run python -m spike.fetch --dcs    # + DCS gold morphology (163 MB) for evaluation
uv run python -m spike.eval_dcs       # split / lexicon accuracy vs DCS → spike/out/dcs_eval.json
uv run python -m spike.draft          # draft analyses for our shlokas → spike/out/drafts/*.yaml
uv run python -m vv_content.seed_build   # regenerate shlokas/*.yaml from the sources
```
